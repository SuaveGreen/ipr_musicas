# 🎸 Music Vault & Chords

Repositório pessoal desenvolvido para organizar meu repertório musical, armazenar cifras formatadas e manter links rápidos de referência no YouTube.

> 🔒 **Projeto Pessoal:** Este repositório é de uso individual e privado. Não aceita contribuições externas.

---

## 📌 Funcionalidades

- **Listagem Paginada:** Divisão do repertório em páginas para navegação rápida e organizada.
- **Visualizador de Cifras:** Exibição da letra com acordes posicionados e indicação de tom.
- **Integração com YouTube:** Link direto no item da música para abrir o vídeo de referência.
- **Sem Banco de Dados:** Músicas gerenciadas e tipadas localmente via arquivos estáticos (`.ts`).

---

## 🛠️ Tecnologias Utilizadas

- **React**
- **TypeScript**
- **Tailwind CSS**
- **Vite**
